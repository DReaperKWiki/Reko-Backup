== 風散翅包子 ==
* 烹飪者：阿飛
* 特色：沒有腥味，口感滑順而不油膩
* 秘密：實際上使用的是海藻萃取物搭配明膠壓製出來的人造魚翅，因而能在短時間內泡開
* 空想度：非空想菜色
* <s>充其量只是為了讓餓昏頭走不動的路以填飽肚子拿梁山泊裡的食譜和材料將就一下的應急食品而已</s>

== 蜜漬金剛五花肉 ==
* 烹飪者：瑪琉、凱由
* 特色：豬肉柔軟富有油脂、和蜜汁一同滲入饅頭，咬下去的滋味能讓人一時忘卻滿身的痛楚
* 秘密：
** 用<s>[[愛]]</s>吸飽了地下水的甘甜嫩竹做成竹筒，以露水形成的對流作用將豬肉蒸熟
** 凱由除了單純重現外還另有使用快速生長的巨型孟宗竹做成的升級版
* 空想度：非空想菜色
* 某種程度上可說是影響了凱由後半輩子的料理

== 行星炒麵 ==
* 烹飪者：亞刊、凱由
* 特色：球狀的炒麵包裹著配料和芡汁，外脆內軟口感豐富
* 秘密：中央灼熱的芡汁讓炒麵不會迅速冷卻<s>秘傳鍋巴炒麵</s>
* 空想度：超空想菜色
** <s>光是調理過程需要用上亞刊的超能力就不必多說了吧</s>

== 核桃麻婆豆腐 ==
* 烹飪者：路以
* 特色：足以讓王嘉見到微弱的光明
* 秘密：用核桃代替絞肉<s>菊下樓出身的也太喜歡做素菜了吧</s>
* 空想度：非空想菜色
* <s>雖然核桃的確是對眼睛有益的食物，但基本不太可能對已經失明的人起作用的才對</s>

== 玉冰獅子頭 ==
* 烹飪者：瑪琉
* 特色：外層包裹著如冰般雞湯凍的獅子頭
* 秘密：雞湯凍和肉丸的滾燙肉汁在口中混和出鮮美的味道
* 空想度：超空想菜色
** 用冷的湯凍包裹熱的肉丸，會直接融化而無法成形

== 全羊席餃子 ==
* 烹飪者：卡卡
* 特色：宛如女真族的傳統宴席「全羊席」，足以讓瀕死之人起死回生
* 秘密：巨大的餃子包入整隻羊的精華與美味
* 空想度：小空想菜色
* 卡卡為了使帝江的靈力最大化所準備的料理<s>但因為沒辦法復活阿昴所以只能當作請人家來的車馬費</s>

== 賽之河原石塔漢堡肉 ==
* 烹飪者：阿昴
* 特色：將賽之河原的石塔用做烤盤的漢堡排，配上白吉饃食用
* 秘密：肉餡使用三途川抓到的鰻魚
* 空想度：超空想菜色
** <s>為什麼三途川裡面會有魚啊?而且中國人死後為什麼會到日本的冥界?</s><ref>小川把日本的地府跟中國的地府融合在一起了，比如奪衣婆跟孟婆是同一個</ref>
** <s>超空想的緣故是還要去一趟冥界</s>

== 三途川鰻魚飯 ==
* 烹飪者：阿昴
* 特色：將三途川的鰻魚用四郎母親傳授的東日本做法炙烤，並附有鰻魚肝湯
* 秘密：烤之前先蒸過縮短烹調時間並使其蓬鬆軟化、搭配溫和的花山椒調味
* 空想度：非空想菜色
** <s>毫無反應，就只是單純的鰻魚飯而已</s>
** 作為三途川的過路費的替代<s>還順帶讓懸衣翁恢復了精力，久未行房的奪衣婆也因此變得對阿昴友善起來了</s>

== 死出山<ref>死者在通過三途川前必須通過的高山</ref>中華涼麵 ==
* 烹飪者：[[李嚴 (中華一番)|李嚴]]
* 特色：將均勻切成細絲的食材跟麵放在超大冰雕盤上，澆上特製的'''醬汁'''讓食用者無法自拔地想將麵條吸入口中，'''醬汁'''也會捨不得的喝到完
* 秘密：<s>李嚴終於完成的</s>蘋果洋蔥配佐料'''醬汁'''裡加入了法式調理法的龍蝦殼高湯並以<s>初戀的滋味</s>葡萄柚襯托其甘甜，麵身則融入了整尾龍蝦磨碎後的精華
* 空想度：
** <s>李嚴終於做好'''醬汁'''了! 他甚至還有時間雕出給五位閻王的五份冰雕盤...</s>

== 清燉棒棒雞涼麵 ==
* 烹飪者：阿昴
* 特色：大盤子裡裝著一整隻全雞，使用筷子輕輕一撥雞肉就會和芝麻醬汁一同擴散開來。
* 秘密：利用巨大蒸籠像壓力鍋般將全雞和裡面的食材加壓製成「清燉全雞」，內部藏有調整過風味並用醋凍包覆的芝麻醬汁來避免醬汁被水分沖淡以及容易吃膩的缺陷。
* 空想度：強空想菜色
** 分量因為評審們都是巨人的關係倒是沒什麼大問題，但要讓醋凍能被筷子戳破的同時又能避免被麵體或雞肉壓破很考驗技術<s>跟運氣</s>
